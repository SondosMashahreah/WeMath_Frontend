# WE MATH Frontend

React + Vite + Three.js. الواجهة تحتفظ بافتتاحية المنصة وخلاياها وألوانها وأحجامها، وتستخدم حسابات فعلية من باك FastAPI.

```bash
npm ci
npm run dev -- --port 5173
```

الباك الافتراضي `http://127.0.0.1:8100`. يمكن تغييره بـ`VITE_API_BASE_URL` في `.env.local` ثم إعادة تشغيل Vite. يحتاج هذا الإصدار باتش الباك المقابل وترحيل قاعدة البيانات. لا توجد مكتبات تشغيل إضافية.

- الطالب يسجل باسم المستخدم وكلمة المرور والصف، ثم يدخل إلى صفه مباشرة.
- الكتاب/الفصل ← الوحدات ← الدروس ← خلايا الكتاب والتعلّم والفيديو والتدريب والاستكشاف والإنجاز.
- الأهل ينشئون أو يربطون حتى خمسة أطفال ويتابعون تقدمهم ويعدلون بياناتهم وكلمات مرورهم وحالة الدخول، ويعاينون منهجهم.
- WE STEAM يفتح `https://steam.ps/` في تبويب جديد.
- الرجوع بالسداسي الكبير أو Escape. تسجيل الخروج من خلية «حسابي» في بداية المساحة.

الكتب الكاملة تبقى كاملة؛ لا يُفترض فصلان لكل كتاب. الموارد الناقصة موسومة «محتوى تجريبي»، والفيديو غير المرفق يظهر كحالة فارغة. كلمات المرور لا تُحفظ في المتصفح؛ يُحفظ رمز الجلسة في sessionStorage للتبويب.

## البنية

قواعد الرحلة والتحقق في `features/student/domain`، ونموذج العرض في `application`، والـAPI في `features/*/infrastructure` و`shared/api`، والواجهات في `features/*/presentation`. الرسم يعيد استخدام المشهد والخامات والإسقاط الأصلي. لا يوجد شريط علوي أو تذييل جديد. معاينة الأهل لا تكتب تقدم الطفل.

```bash
npm run lint
npm run test:student
npm run test:geometry
npm run test:bee
npm run build
```

[دليل التحديث](docs/PLATFORM-UPDATE.md) هو المرجع الحالي. وثيقة STUDENT-UI-UX.md تصف المعاينة التاريخية السابقة فقط.
