# WE MATH — المشهد فقط

مشروع React + Vite + JavaScript، بافتتاحية Three.js تلقائية وخلفية سادة `#DED3C8`، ثم سداسي مركزي يفتح عشرة سداسيات صغيرة. لا توجد صفحات داخلية، روابط، لوحات، تجارب تعليمية أو شريط أسفل الشاشة.

## التشغيل

استخدمي Node.js 22.12 أو أحدث:

```bash
npm ci
npm run dev -- --port 5174
```

البكيج الجديد `react-icons` مضاف في `package.json` وملف القفل؛ يثبّته `npm ci` تلقائيًا. أزيلت `lenis` وTailwind لأن المشهد الحالي لا يستخدمهما. التنسيق CSS عادي.

## تطبيق التعديل على النسخة السابقة

باتش `we-math-clean-upgrade.patch` يُطبّق **فوق آخر نسخة Bee**؛ أي بعد تطبيق `we-math-bee-upgrade.patch` السابق. من داخل مجلد مشروعك:

```bash
git apply --check we-math-clean-upgrade.patch
git apply we-math-clean-upgrade.patch
npm ci
npm run dev -- --port 5174
```

إذا فشل أمر الفحص، لا تطبّقي الباتش فوق تعديلاتك بالقوة. المشروع الكامل المرفق يعمل في مجلد مستقل، ويمكنك مقارنة ملفاته بنسختك. احتفظي بتعديلاتك المحلية قبل الاستبدال.

## تسلسل الحركة

1. تظهر الحروف المجسّمة نفسها بانبثاق خفيف، ثم تمر عليها لمعة واحدة. أزيلت عبارة التحميل الثابتة المنفصلة.
2. تكمل الحروف التحوّل إلى القطع ثم القطاعات، وتلتئم في دائرة موحّدة اللون.
3. تظهر WE وMATH داخل الدائرة، ثم يتحوّل محيطها إلى سداسي.
4. الضغط على السداسي الكبير يفتح عشرة سداسيات؛ الضغط عليه مرة أخرى يغلقها.
5. السداسيات الصغيرة للعرض حاليًا: لا يوجد فيها `onClick` ولا روابط ولا انتقالات لصفحات.

على اللابتوب، السداسيان الإضافيان في أقصى اليسار واليمين. على الهاتف والشاشات العمودية، ينتقلان إلى أعلى وأسفل المركز. تكبر السداسيات الصغيرة نسبيًا على الهاتف لاستيعاب العناوين العربية.

لا توجد نجوم، نحلات، خلايا خلفية، رموز عائمة أو نصوص أسفل الشاشة. تبقى إضاءة المجسّمات وظلالها لإظهار العمق.

## أين أعدّل؟

| الملف | وظيفته |
| --- | --- |
| `src/lib/beeConfig.js` | العناوين، تقسيم الأسطر، مواضع اللابتوب والهاتف، الألوان الرئيسية ومدة الافتتاحية |
| `src/components/HiveIcon.jsx` | أسماء أيقونات React Icons وخريطة ربطها بالأزرار |

| `src/styles/bee.css` | الخطوط، تنسيق العناوين والأيقونات وحالات التركيز |
| `src/scene/beeScene.js` | الحروف والقطاعات والسداسيات المجسّمة، الانبثاق واللمعة، الكاميرا والإضاءة |

| `index.html` | عنوان الموقع ووصفه |

### تعديل عنوان أو موقع

كل عنصر في `HIVE_ITEMS` يملك:

```js
{
  id: "assistant",
  label: "المساعد الذكي",        // الاسم الكامل لقارئ الشاشة
  lines: ["المساعد", "الذكي"],  // الأسطر الظاهرة داخل السداسي
  desktop: { x: -1.88, y: 2.32 },
  mobile: { x: -1.6, y: 2.33 },
}
```

`x` الموجب إلى اليمين، و`y` الموجب إلى الأعلى. احتفظي بالمعرّف `id` عند تغيير الاسم أو الموقع، لأنه يربط الزر بأيقونته والمجسّم المقابل له.

### تغيير الأيقونات

في `HiveIcon.jsx` استبدلي الأيقونة المستوردة ثم بدّلي اسمها داخل `ICONS`. مثال:

```jsx
import { FaLightbulb } from "react-icons/fa6";

// داخل ICONS:
assistant: FaLightbulb,
```

يمكن اختيار الأيقونات من [مكتبة React Icons](https://react-icons.github.io/react-icons/). لا تحتاجين لتعديل هندسة Three.js لتغييرها. العناوين العربية والأيقونات مكوّنات React تُسقط على الوجه الأمامي للسداسي، فتتبع موضعه وحجمه وميله؛ أجسام السداسيات نفسها مجسّمات فعلية.

### الألوان والمدة

`BEE_THEME` يحتوي ألوان الخلفية والسداسي الرئيسي وحواف المجسّمات والسطح الفاتح والنص والأيقونات. `INTRO_DURATION` يحدد مدة الافتتاحية كاملة بالثواني؛ الافتراضي `17.6`. اتركي `STORY_DURATION` و`ENTRANCE_DELAY` كما هما عند تغيير سرعة العرض فقط.

## الملفات المحذوفة

أزيلت ملفات `Journey.jsx` و`Lab.jsx` و`Atmosphere.jsx` و`Sculpture.jsx` و`journey.css` والصور والأيقونات القديمة غير المستخدمة. أزيلت جميع شيفرات المختبرات وAbout والنوافذ والنجوم والنحل والزخارف من المشهد الحالي أيضًا؛ ليست مجرد عناصر مخفية.

## لوحة المفاتيح والتحقق

- `Escape` يتجاوز الافتتاحية أو يغلق السداسيات الصغيرة.
- `Tab` ينقل التركيز بين الأزرار. `Enter` أو `Space` يفتح أو يغلق السداسي المركزي؛ السداسيات الصغيرة لا تنفّذ أي إجراء.
- إعداد «تقليل الحركة» في النظام يعرض السداسي النهائي مباشرة.

```bash
npm run lint
npm run test:geometry
npm run test:bee
npm run build
```

نجحت فحوص الكود والهندسة والبناء. فُحص المشهد حسابيًا باستخدام Three.js: 177 لحظة من الافتتاحية، اكتمال الدائرة قبل السداسي، وعدم تداخل مناطق الضغط أو خروجها عن الشاشة في سبعة أحجام بين الهاتف واللابتوب. وفُحصت قياسات العناوين العربية الطويلة بالخط المضمّن.

تعذّر تشغيل المتصفح في بيئة تجهيز هذه النسخة؛ فحوص الإحداثيات والخطوط لا تغني عن المعاينة الفعلية للحركة والرسم على GPU على جهازك.
