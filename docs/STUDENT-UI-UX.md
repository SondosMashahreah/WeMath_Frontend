# واجهة الطالب — WE MATH

```text
55801b2876c3bf31d72dcc603027313096fe0710
edit animation — 2026-10-14
```

## تركيب الباتش

لتحديث واجهة الطالب المثبّتة سابقًا إلى المقاسات والتصميم المطابقين للصفحة الأولى، ضعي `we-math-student-sizing.patch` في جذر المشروع ثم نفّذي:

```bash
git apply --check we-math-student-sizing.patch
git apply we-math-student-sizing.patch
```

هذا باتش إضافي فوق `we-math-student-ui-ux.patch` السابق، وليس بديلًا عنه. افتحي نفس خادم التطوير الحالي على `http://localhost:5173`؛ إذا كان مغلقًا شغّليه بـ `npm run dev -- --port 5173`.

### التثبيت الأول للواجهة

ضعي ملف `we-math-student-ui-ux.patch` في جذر المشروع الذي يحتوي `package.json`. من Terminal داخل المشروع:

```bash
git apply --check we-math-student-ui-ux.patch
git apply we-math-student-ui-ux.patch
npm run dev -- --port 5173
```

الفحص الأول يتحقق من قابلية تطبيق الباتش دون تعديل الملفات. إذا ظهرت تعارضات، اتركي ملفاتك الحالية كما هي وراجعي اختلاف نسختك عن الالتزام المذكور أعلاه. لا تحذفي `beeScene.js` أو مجلد `src`؛ الباتش يُحدّث الملفات الموجودة ويضيف الملفات الجديدة بمساراتها.

لا توجد مكتبات تشغيل جديدة، ولا تغيير على `package-lock.json`. يحتاج المشروع نفس إصدار Node المحدد في `package.json`.

## الرحلة المنفّذة

1. الصفحة الأولى وافتتاحيتها وألوانها وتدرّجها وهندستها تبقى كما في GitHub.
2. الضغط على خلية الطلاب يفتح نافذة على شكل خلية، فيها تسجيل الدخول أو إنشاء حساب.
3. تسجيل الدخول: اسم المستخدم وكلمة المرور، مع إظهار/إخفاء كلمة المرور وتنبيهات الحقول.
4. إنشاء حساب: اسم الطالب، رقم الهوية، المدرسة، الهاتف، البريد الإلكتروني، المديرية.
5. بعد إكمال النموذج، يصبح السداسي الكبير «الطالب»، وتظهر 12 خلية بأرقام الصفوف 1–12. الصف 12 يبقى اختيارًا واحدًا.
6. اختيار الصف يضعه في السداسي الكبير ويُظهر خليتين فقط: الفصل الأول والفصل الثاني.
7. اختيار الفصل يضعه في السداسي الكبير ويُظهر الوحدات.
8. اختيار الوحدة يضعها في السداسي الكبير ويُظهر الدروس.
9. اختيار الدرس يحدّده ويعلن اختياره. لا توجد شاشة لمحتوى الدرس في هذا التحديث.

واجهات الصفوف والفصول والوحدات والدروس تعرض السداسي الكبير والخلايا الصغيرة فقط، دون شريط علوي أو ترحيب أو مسار تعلّم أو عناوين وتذييل مرئيين. مساحة الرسم تستخدم ارتفاع الشاشة كاملًا. على الكمبيوتر يأتي موضع السداسي الكبير ومقاسه مباشرةً من مرجع الصفحة الأولى `DESKTOP_HIVE`، والخلايا الصغيرة تأخذ أبعاد خلية الطلاب نفسها ولا يتغيّر مقاسها عند الانتقال بين المراحل. الصفوف الاثنا عشر تتوزّع في أربعة أعمدة متداخلة دون تقاطع الخلايا.

الرجوع متاح من السداسي الكبير أو مفتاح Escape. من شاشة الصفوف يعود إلى الصفحة الأولى، ويحافظ على الخلايا مفتوحة ولا يعيد تشغيل الافتتاحية. على الهاتف تتوزّع الخلايا تحت السداسي الكبير مع تمرير رأسي عند الحاجة ودون شريط تمرير مرئي. الخلايا الصغيرة تستخدم نفس الإطارات الثابتة والسطح الداخلي المتحرك، وتراعي إعداد تقليل الحركة. تبقى عناوين المراحل وإعلان اختيار الدرس متاحة لقارئات الشاشة.

## حدود المعاينة

هذه واجهة UI/UX فقط. إكمال النموذج يُدخل إلى المعاينة، ولا يتحقق من حساب أو ينشئ حسابًا على خادم. لا تُرسل بيانات النموذج، ولا تُكتب في `localStorage` أو `sessionStorage`. يبقى اسم العرض في ذاكرة الصفحة حتى إعادة التحميل، دون عرضه في الرحلة؛ بقية حقول التسجيل وكلمة المرور لا تنتقل إلى رحلة التعلّم. لتجربة إنشاء حساب من جديد، أعيدي تحميل الصفحة ثم افتحي خلية الطلاب.

الوحدات والدروس بيانات للمعاينة: ست وحدات مرقّمة وأربعة دروس مرقّمة لكل وحدة. هذه الأعداد والأسماء لا تمثل منهاجًا رسميًا. لا توجد تصنيفات علمي/أدبي للصف 12 بعد.

## البنية وفصل المسؤوليات

| المسار | المسؤولية |
| --- | --- |
| `src/features/student/domain/journey.js` | قواعد الاختيارات والرجوع وإزالة اختيارات المراحل التابعة |
| `src/features/student/domain/accessValidation.js` | حقول التسجيل والتحقق المحلي من المدخلات |
| `src/features/student/application/presentJourney.js` | تحويل الاختيارات إلى عنوان وخلايا ومسار تنقّل، من خلال مستودع بيانات يُمرّر إليه |
| `src/features/student/application/useStudentJourney.js` | ربط حالة الرحلة بواجهة React |
| `src/features/student/infrastructure/previewCurriculumRepository.js` | بيانات الوحدات والدروس التجريبية، قابلة للاستبدال بمصدر المحتوى الحقيقي |
| `src/features/student/presentation/` | النماذج والخلايا والتنسيق وحساب المواضع ومحوّل Three.js |
| `src/features/student/StudentExperience.jsx` | تجميع الواجهة وحقن مستودع البيانات وإدارة الانتقال من الصفحة الأولى |
| `src/scene/hive/rendering.js` | الإضاءة والخامات والهندسة المشتركة مع الصفحة الأولى |
| `src/scene/hive/projection.js` | إسقاط أزرار HTML والنص العربي على وجوه المجسّمات |

قواعد الرحلة لا تعتمد على React أو Three.js أو DOM. نموذج العرض يعتمد على واجهة مصدر البيانات (`listUnits` و`listLessons`)، ولا يستورد البيانات التجريبية مباشرة. محوّل الرسم يستقبل عناصر العرض فقط ولا يعرف حقول الحساب. مصدر البيانات يُمرّر من نقطة التجميع.

تم استخراج أدوات الرسم والإسقاط الموجودة أصلًا إلى ملفات مشتركة بدل تكرارها. `smallHive.js` يقبل عناصر ومواضع مخصّصة، وتبقى قيمه الافتراضية هي خلايا الصفحة الأولى. لم تتغير ملفات `beeConfig.js` أو `hiveColors.js` أو `geometry.js` أو الأيقونات أو تنسيق الصفحة الأولى.

لتغيير أسماء الوحدات والدروس، حدّثي مستودع البيانات التجريبية مع الحفاظ على المعرّفات الثابتة وواجهتي `listUnits(grade, semester)` و`listLessons(grade, semester, unitId)`. دعم بيانات الخادم والمصادقة الفعلية مرحلة منفصلة.

## التحقق

```bash
npm run build
npm run lint
npm run test:student
```

اختبارات الرحلة تغطي الصفوف الاثني عشر والفصلين والوحدات والدروس، والرجوع وإلغاء الاختيارات التابعة، وحقول التسجيل، وعدم تداخل الخلايا أو قصّها على تسعة مقاسات تشمل أبعاد الصورة المرجعية 1917×907. تتحقق كذلك من تطابق السداسي الكبير مع مقاسه وموضعه في الصفحة الأولى، وثبات مقاس الخلايا الصغيرة بين المراحل، وعدم تجاوز ارتفاع الشاشة على الكمبيوتر.

أثناء تجهيز التحديث فُحص كذلك:

- التفاعل مع واجهة React داخل DOM: فتح خلية الدخول، التحقق من النماذج، إظهار كلمة المرور، التنقّل والرجوع بالسداسي الكبير وEscape، العودة للرئيسية وإغلاق النافذة، وغياب العناصر الإضافية عن الرحلة.
- مشهد Three.js الفعلي مع بديل لواجهة GPU: مطابقة هندسة الصفحة الأولى وخاماتها والتدرّج ومواضع الأزرار أثناء الافتتاحية وبعد فتح الخلايا على ستة مقاسات.
- ثلاثون حالة لعدد خلايا الطالب والمقاس، تشمل إسقاط الأزرار، ثبات الإطارات، اتجاه اللفة، قراءة الوجه الخلفي، وتحرير الموارد عند تغيير المرحلة.

تعذّر تشغيل Chromium في بيئة التنفيذ. لذلك تفاعل DOM والهندسة فُحصا آليًا، لكن الإضاءة الفعلية في WebGL والتخطيط النهائي داخل المتصفح يحتاجان معاينة على جهازك.
