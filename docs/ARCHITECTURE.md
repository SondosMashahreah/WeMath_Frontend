# WE MATH — تنظيم الصفحات والمسارات

التنقّل أصبح مبنيًا على React Router. كل صفحة ودرس ونشاط له رابط، ويمكن استعمال الرجوع والتقدم وفتح رابط داخلي مباشرة. لم تتغيّر هندسة الخلايا أو ألوانها أو الخطوط أو محتويات الكتب. الطالب يدخل صفه المحفوظ؛ الأهل لهم مساحة منفصلة؛ WE STEAM يبقى رابطًا خارجيًا.

## فصل المسؤوليات

| المسار | المسؤولية |
| --- | --- |
| `src/app/routing/` | سجل المسارات، حراس الأدوار، وصفحة خطأ المسار |
| `src/app/layouts/` | التخطيط الثابت الذي يجمع المشهد الرئيسي و`Outlet` |
| `src/app/providers/` | تجميع مزوّدي الجلسات والفهرس والذاكرة |
| `src/features/*/domain/` | قواعد خالصة والتحقق من المدخلات دون React أو شبكة |
| `src/features/*/application/` | hooks وحالات الاستخدام: الجلسات، الرحلة، التقدم، المسودات والمحتوى |
| `src/features/*/infrastructure/` | مستودعات API وتحويل البيانات |
| `src/features/*/presentation/pages/` | صفحات مرتبطة بمسارات محددة |
| `src/features/*/presentation/` | نماذج ومكوّنات عرض قابلة لإعادة الاستخدام |
| `src/shared/hive/` | الخلايا، قياساتها، ومحوّل Three.js المشترك |
| `src/shared/presentation/` | النافذة السداسية ورسائل التحميل والخطأ |
| `src/shared/routing/` | بناء الروابط، التنقّل، إغلاق النوافذ وقراءة query parameters |
| `src/shared/state/` | ذاكرة مسودات المعلّم ومحادثة Algo أثناء التنقّل |
| `src/shared/api/` | عميل API المشترك لجلسة العائلة |
| `src/scene/` | الرسم والهندسة؛ لا يعتمد على الحسابات أو الصفحات |

ينشئ `main.jsx` router واحدًا خارج شجرة React. يركّب `App` مزوّدي الحالة و`RouterProvider`. يبقى `AppLayout` والمشهد الرئيسي مركّبين، ويُوقَف المشهد عند إخفائه؛ الرجوع للرئيسية لا يعيد الافتتاحية. عند فتح رابط داخلي مباشرة يتم تجاوز الافتتاحية.

قواعد domain لا تستورد React أو fetch. الصفحات تتعامل مع hooks والمستودعات، ولا تستدعي fetch مباشرة. أدوات بناء الروابط مستقلة عن React. بقيت إعادة تصدير ملفات الخلايا في مسارات الطالب القديمة للتوافق؛ التنفيذ الفعلي موجود مرة واحدة في shared.

## المسارات

| الصفحة | URL |
| --- | --- |
| الرئيسية | `/` |
| دخول/تسجيل الطالب | `/student/login`، `/student/register` |
| كتب صف الطالب المحفوظ | `/student` |
| وحدات كتاب | `/student/books/:bookId` |
| دروس وحدة | `/student/books/:bookId/units/:unitId` |
| نشاطات درس | `/student/books/:bookId/units/:unitId/lessons/:lessonId` |
| نشاط محدد | مسار الدرس + `/activities/learn` أو `video` أو `practice` أو `game` |
| حساب الطالب | `/student/account` |
| الأهل | `/parent` |
| إضافة/إنشاء/ربط طفل | `/parent/children/add`، `/parent/children/create`، `/parent/children/link` |
| الطفل | `/parent/children/:childId` |
| بيانات/كلمة مرور/تقدم الطفل | مسار الطفل + `/edit` أو `/password` أو `/progress` |
| معاينة منهج الطفل | مسار الطفل + `/curriculum` ثم نفس تسلسل الكتب والوحدات والدروس |
| المعلّم | `/teachers`، `/teachers/login`، `/teachers/register` |
| منهاج المعلّم | `/teachers/curriculum/grades/:grade/books/:bookId/units/:unitId/lessons/:lessonId`؛ كل مستوى صفحة أيضًا |
| التحاضير | `/teachers/plans`، `/teachers/plans/new`، `/teachers/plans/:documentId`، `/teachers/plans/:documentId/edit` |
| الاختبارات | نفس تسلسل التحاضير تحت `/teachers/assessments` |
| مكتبة المعلّم | `/teachers/resources/:category/:entryId`؛ القسم والقائمة صفحتان أيضًا |
| ورش المعلّم | `/teachers/workshops/:category/:entryId` |
| المحتوى العام | `/:section/:category/:entryId`؛ section هو `workshops` أو `competitions` أو `initiatives` أو `research` |
| الزائر | `/guest/grades/:grade/books/:bookId`؛ اختيار الصف والكتاب صفحتان أيضًا |
| Algo | `/assistant/calculate`، `/assistant/search` |

WE STEAM يفتح `https://steam.ps/` خارجيًا. حارس الدور يتحقق من الجلسة قبل عرض الصفحات الخاصة. تتحقق الواجهة من صف الطالب وارتباط الوحدات والدروس بالكتاب وملكية الطفل، وتبقى صلاحيات الخادم هي المرجع النهائي.

## توزيع الحالة

- **المسار:** الصفحة والكتاب والوحدة والدرس والنشاط والطفل وملف المعلّم.
- **Query:** البحث `q`، الصفحة `page`، الأرشيف `archived=1`، الشهر `month=YYYY-MM`، ونافذة البحث أو التقويم `panel`. تبقى هذه الخيارات عند الرجوع أو تحديث المتصفح.
- **Providers:** جلسة العائلة وجلسة المعلّم المستقلة وفهرس الكتب المحمّل مرة واحدة. عند تحديث المتصفح تُستعاد الجلسة من الخادم، ويُقرأ الرابط لفتح نفس الصفحة.
- **ذاكرة التطبيق:** مسودات التحاضير والاختبارات وآخر ست إجابات لكل وضع Algo. تبقى أثناء التنقّل داخل التطبيق، وتُمحى عند تحديث المتصفح. مسودات المعلّم مفصولة بحسب الحساب ونوع الملف ومعرّفه، وتُمحى عند الخروج أو انتهاء الجلسة.
- **State محلي:** الحقول غير المحفوظة في نماذج الحساب، إظهار كلمة المرور، أخطاء الطلبات وإجابات النشاط المفتوح.
- **الخادم:** الحسابات والتقدّم وملفات المعلّم المحفوظة.

لا توضع كلمات المرور أو الرموز في URL أو ذاكرة المسودات. `next` بعد الدخول يقبل مسارًا داخليًا تابعًا للدور فقط. المسودة تحتفظ بإصدار الملف الذي بدأت منه حتى لا تتجاوز حماية تعارض الإصدارات؛ يمكن تجاهلها والبدء من النسخة المحمّلة.

زر إغلاق النافذة يرجع خطوة في history إذا كانت الصفحة السابقة هي الأب المتوقع، وإلا ينتقل للأب مباشرة. معاينة الأهل للمنهج لا تكتب تقدّمًا للطالب. زر إكمال الدرس يبقى فعل حفظ، وليس صفحة مستقلة.

## إضافة صفحة لاحقًا

1. ضعي التحقق والقواعد الخالصة في domain وطلبات API في infrastructure والتنسيق بينهما في application.
2. أنشئي صفحة داخل `presentation/pages/` وأعيدي استخدام الخلايا والنافذة الموجودة.
3. أضيفي المسار في `app/routing/routes.jsx` تحت حارس الدور المناسب، وباني الرابط في `shared/routing/paths.js` إذا استُعمل أكثر من مرة.
4. استخدمي `go` أو `Link` للتنقّل الداخلي؛ لا تستعملي reload أو location.href لهذا الغرض. الروابط الخارجية تبقى روابط عادية.
5. اختبري فتح الصفحة مباشرة، الرجوع، واختلاف الدور أو المعرّف.

## التشغيل والفحوص

بعد تطبيق الباتش: `npm ci`. أضيف React Router كاعتماد تشغيل، وesbuild وjsdom لاختبار الصفحات.

```sh
npm run lint
npm run build
npm run test:student
npm run test:routing
npm run test:geometry
npm run test:bee
```

اختبار routing يشغّل React وBrowserRouter والتاريخ وهندسة Three.js داخل JSDOM؛ الشبكة وGPU وساعة الحركة بدائل اختبار. لا يغني ذلك عن معاينة WebGL والطباعة والموبايل في متصفح حقيقي. اختبارات الباك تفحص API الفعلي مع قاعدة اختبار منفصلة.

## فتح رابط داخلي بعد النشر

Vite في التطوير و`vite preview` يدعمان SPA fallback. في الاستضافة، اجعلي مسارات الواجهة التي لا تطابق ملفًا ترجع `index.html` بحالة 200، مع إبقاء `/api/` منفصلًا. مثال Nginx لواجهة مستضافة على جذر الموقع:

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

عند النشر تحت مجلد، اضبطي `base` في Vite واجعلي fallback يشير إلى index.html الخاص به؛ الـrouter يقرأ `import.meta.env.BASE_URL`.

## تعديل الباك

أضيف `GET /api/platform/teachers/library/{entry_id}` لفتح تفاصيل مادة معلّم عبر رابط مباشر. يتطلب جلسة معلّم، ويرفض المادة غير المنشورة أو التابعة لقسم عام. لا توجد migration جديدة أو تغييرات على `.env` أو JWT أو حسابات الأهل والطلاب.
