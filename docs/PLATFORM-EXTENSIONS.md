# WE MATH — الأقسام المكملة

تحديث إضافي فوق باتش المنصة السابق وإصلاح فصل دخول الطالب عن الأهل. لا يغيّر ملفات الطالب أو الأهل أو WE STEAM أو المشهد والألوان والخطوط. ملف الربط الوحيد المعدّل في الفرونت هو `src/App.jsx`؛ بقية الإضافة داخل `src/features/platform/`.

## المسارات المضافة

| المدخل | ما يمكن فعله |
| --- | --- |
| المعلّم | إنشاء حساب/دخول باسم المستخدم وكلمة المرور، استعادة الجلسة، المنهاج حسب الصف والكتاب والوحدة والدرس، فتح الكتب، تحضير وحفظ وتعديل وأرشفة واستعادة خطط الدروس، إنشاء اختبارات وطباعة نسخة الطالب أو نموذج الإجابة، أنشطة وألعاب وبنك أسئلة وورش |
| الزائر | معاينة الكتب ودرس واحد من كل كتاب، بلا تسجيل أو حفظ تقدم |
| الورشات | علمية، جامعات ومؤسسات، مديريات؛ بحث وأرشيف وتفاصيل |
| المسابقات | علمية ودولية، تقويم شهري، بحث وأرشيف |
| المبادرات | مدارس ومديريات ومعلمون وطلاب، وقصص نجاح المعلمين والطلاب والمدارس |
| الأبحاث والدراسات | أبحاث علمية وصفية، بحث وتفاصيل ومصدر عند توفره |
| Algo | حساب محدود مع خطوات وبحث في عنوان الدرس؛ نسخة تجريبية دون اتصال بنموذج لغوي |

كل القوائم تستخدم `StudentHive` الحالي وقياساته. النوافذ تستخدم الغلاف السداسي الحالي. الصفحات مقسمة لمنع ازدحام الخلايا، والعناوين الطويلة مختصرة بصريًا وتظل كاملة في الوصف المتاح لقارئ الشاشة والتفاصيل.

## العزل

- اعتراض النقر محصور في مداخل الأقسام السبعة أعلاه. نقرات `students` و`parents` و`steam` تمر إلى المعالجات الموجودة كما هي.
- الشجرة القديمة تبقى مركبة أثناء زيارة قسم جديد؛ تعود كما كانت عند الرجوع. زر Escape في الأقسام الجديدة معزول عن مستمع الصفحة القديمة.
- جلسة المعلّم في `sessionStorage["wemath.teacher.session.v1"]`؛ الإضافة لا تقرأ أو تعدّل جلسة العائلة.
- واجهات المعلّم الخاصة ترسل JWT المعلّم فقط. الطلبات العامة لا ترسل أي جلسة. انتهاء الجلسة يعيد شاشة دخول المعلّم.
- أوراق الاختبارات تخفي نموذج الإجابة افتراضيًا. تفعيله خيار صريح قبل الطباعة.
- CSS الإضافة محصور في عناصرها؛ تنسيق الطباعة يعمل فقط عند فتح ملف معلّم قابل للطباعة.

## التشغيل والفحص

تستخدم الإضافة `VITE_API_BASE_URL` الموجود (الافتراضي `http://127.0.0.1:8100`). لا توجد حزم تشغيل جديدة. طبّق باتش الباك وترقية Alembic قبل الاستخدام.

```powershell
node --test tests/platform-expansion.test.mjs
npm run lint
npm run build
npm run dev -- --port 5173
```

المحتوى الجديد يبدأ بـ27 سجلًا تجريبيًا موضحًا على الواجهة. لا توجد جهات أو فعاليات أو أبحاث منسوبة إلى أشخاص وهميين على أنها حقيقية. رابط المصدر يظهر فقط عند إدخاله. الكتب تأتي من الفهرس الموجود.

فحوص التسليم: اختبارات عزل الجلسات والمداخل والروابط، lint، بناء الإنتاج، وتشغيل React مع API حقيقي وقاعدة PostgreSQL مضمّنة للاختبار. تم استبدال GPU وسطح المتصفح أثناء الاختبار الآلي؛ يلزم فحص بصري نهائي في متصفحك، خصوصًا الطباعة والموبايل. لم يُجر اختبار تحميل إنتاجي.
