# فصل دخول الطلاب عن الأهل

هذا تحديث إضافي فوق `wemath-frontend-platform.patch`. يُطبّق داخل WeMath_Frontend فقط.

## السلوك

- زر الطلاب يفتح تسجيل دخول الطالب مباشرة بالـusername وكلمة المرور. الحساب الذي أنشأه ولي الأمر والحساب الذي أنشأه الطالب بنفسه يستخدمان المسار نفسه.
- الطالب يصل إلى صفه المحفوظ وأنشطته. إذا كانت جلسة الطالب نفسها فعالة، يرجع إلى صفه مباشرة.
- إنشاء حساب الطالب يطلب أربعة حقول: الاسم، اسم المستخدم، كلمة المرور، الصف.
- زر الأهل يفتح مساحة الأهل. بيانات حساب أهل لا تدخل عبر بوابة الطالب، والعكس صحيح.
- حساب واحد يكون نشطًا في التبويب. الانتقال إلى مساحة بدور مختلف يطلب بيانات حسابها، ولا يستعمل جلسة الحساب السابق. لا يغير ذلك بيانات الحساب أو علاقات الأطفال.
- استعادة جلسة قديمة متأخرة أو إغلاق نموذج الدخول لا يسمحان بتحويل الطالب إلى حساب أهل.
- الحسابات القديمة التي تحتاج صفًا تستكمله مرة واحدة كما في التحديث السابق.

الباتش يعيد استخدام السداسيات والتصميم الحاليين. لا يحتاج تعديلًا في الباك أو ترحيلًا جديدًا لقاعدة البيانات.

## التطبيق في PowerShell

ضع الملف بجانب مجلد WeMath_Frontend، ثم من داخله:

```powershell
git apply --check ..\wemath-frontend-student-entry-fix.patch
git apply ..\wemath-frontend-student-entry-fix.patch
npm run dev -- --port 5173
```

إذا كان Vite يعمل بالفعل، أوقفه بـ Ctrl+C قبل تشغيله مجددًا. حدّث صفحة المتصفح بعد التطبيق. إذا فشل فحص الباتش، لا تفرض تطبيقه؛ رسالة الخطأ تحدد الملفات التي تختلف عن النسخة السابقة.

## التحقق

تمت إعادة إنتاج الخلل قبل الإصلاح: دخول الأهل ثم الرجوع واختيار الطلاب كان يفتح مساحة الأهل. بعد الإصلاح نجحت الرحلة نفسها عبر React مع الـAPI الفعلي وقاعدة PostgreSQL المضمّنة PGlite، بما في ذلك رفض الدور الخطأ في الاتجاهين، تسجيل الطالب بنفسه، الحساب المنشأ من الأهل، الصف المحفوظ، التقدم، معاينة الأهل، تغيير الصف وكلمة المرور، واستعادة جلسة متأخرة. تم استبدال عرض GPU في الاختبار؛ ليس فحصًا بصريًا لمتصفح فعلي.

نجحت اختبارات الفرونت الاثنا عشر وlint وbuild. الاختبارات الجديدة في `tests/account-access.test.mjs` تغطي فصل الأدوار ومنع تثبيت جلسة ناتجة عن طلب ملغى.

```bash
npm run test:student
npm run lint
npm run build
```

للتجربة اليدوية: ادخل كولي أمر، ارجع للصفحة الرئيسية ثم اختر الطلاب. يجب أن ترى اسم المستخدم وكلمة المرور فقط. جرّب بيانات ولي الأمر للتأكد من رفضها، ثم بيانات الطفل للتأكد من وصوله إلى صفه. جرّب إنشاء حساب طالب بنفسه، ثم ارجع إلى الأهل وتحقق من استمرار بيانات الأطفال وتقدمهم.
